# Transcriptomic & Genomic Expression Analysis

Bioinformatics coursework analysing gene-expression data through the full RNA-seq workflow, using the Galaxy platform. Keele University, Omics Technologies.

## Overview
This project runs the standard transcriptomics pipeline on an 11-sample whole-transcriptome RNA-seq dataset (6 liver, 5 lung) and interprets the biology behind the results — bridging computational analysis and clinical meaning.

## Workflow
1. **Quality control** — raw read QC.
2. **Read alignment** — mapping reads to the reference.
3. **Differential expression analysis** — identifying significantly up-/down-regulated genes.
4. **Statistical visualisation** — volcano plots, expression summaries.
5. **Interpretation** — translating findings into a clinical context for non-specialist audiences.

## What's inside
- `whole_transcriptome_analysis.docx` — whole-transcriptome analysis write-up
- `genomics_analysis.docx` — supporting genomics analysis

## Tools & concepts
Galaxy platform · RNA-seq · differential expression · multiple-testing correction · biological interpretation

## Note
This repository documents analysis carried out largely through the Galaxy web platform, so it centres on methodology and interpretation write-ups rather than standalone scripts.
